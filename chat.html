连接你的 AI 网关

聊天台直连 new-api 网关，密钥只存在你的浏览器，站方不存储对话。

  1. 部署好 new-api，后台「渠道」里配置上游模型
  2. 后台「令牌」页创建一个 API Key
  3. 把站点地址和 Key 填在下面，开聊

提示：地址必须是公网可访问的 HTTPS（或已配置跨域白名单），浏览器才能直连。本地 localhost 地址仅在本机打开时可用。
